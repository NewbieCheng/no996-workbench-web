## 使用规则

允许按所附 OFL 使用、嵌入及随软件分发九款字体；字体本身不得单独销售。分发字体须保留版权声明和完整许可；修改版须遵守保留字体名及作者署名约束，不能擅用权利人名义背书。字体和衍生字体继续受 OFL 约束；使用字体产生的视频等作品不因此必须使用 OFL。

字幕选择真实 family 和实际字重，九款 OFL 字体均使用本项目声明的 400 静态 face；普惠体默认 700。字体由本项目本地依赖的 CSS 注册，选择和导出前等待真实 face 加载，失败明确报错，不把系统字体回退当作成功。

六个内容镜头固定使用普惠体标题 700、副标题 400，独立等待这两个字重；字幕换成其他字体时也不会跳过镜头字体准备。离线镜头出帧还须把实际使用字体嵌入图像，单纯等待页面字体并不能证明嵌入正确。
